# ארקייד בריינרוט משפחתי

אב טיפוס פרטי למשחק דפדפן משפחתי, מבוסס Phaser 3.

## הרצה

אפשר לפתוח את `index.html` בדפדפן, או להריץ שרת סטטי מקומי:

```powershell
C:\Users\bentu\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe tools\static-server.mjs 4173
```

ואז לפתוח את `http://127.0.0.1:4173`.

אין צורך בתהליך build. Phaser שמור מקומית ב-`vendor/phaser.min.js`.
הדמויות נטענות כקבצי PNG ריאליסטיים-קריקטוריים מתוך `assets/characters`, עם ציור קנבס פנימי כגיבוי בלבד.
רקעים לכל שלב נטענים מתוך `assets/backgrounds`, ופסטה/רוטב נטענים מתוך `assets/items`.

## מצבים

- מירוץ: מתחרים ביריב במסלול מבוך גדול יותר עם 10 שלבים מדורגים מהקל לקשה מאוד. היריב רץ במסדרונות חוקיים, אוספים פסטה, נמנעים משלוליות רוטב ומגיעים לשער הסיום לפניו.
- אתגר התהום: משחק ריצה וקפיצה אוטומטי ל-1,000 מטר עם חמישה אזורי קושי, שלוש נפילות, נקודות ביקורת, פלטפורמות מתפוררות ופסטה כבונוס מרחק.
- דפי צביעה: `coloring.html` הוא דף mobile-first עם שמונה דפי צביעה לפי מספרים, מילוי צבע בנגיעה, רמזים, ביטול, איפוס ושמירת התמונה.
- מעבדת ממים: יוצרים דמויות בריינרוט משפחתיות חדשות מחיה, אוכל ותכונה.
- קרב: לכל דמות יכולת ייחודית, אבל יש גם מכה קרובה, הגנה, התחמקות ופוקוס. מנצחים כשמורידים את היריב ל-0 HP.

## שליטה

- מירוץ: ההוראות נשארות על המסך עד שלוחצים על מקש או כפתור שליטה. חיצים או `W/A/S/D` לתנועה. החזקת `Space` או כפתור `טורבו` מפעילה טורבו וצורכת אנרגיה. `R` מתחיל מחדש אחרי סיום.
- אתגר התהום: `Space`, חץ למעלה, `W` או כפתור `קפיצה`. לחיצה קצרה יוצרת קפיצה נמוכה ולחיצה ארוכה קפיצה גבוהה. `R` מתחיל מחדש אחרי ניצחון או הפסד.
- קרב: `A/D` או חיצים לתנועה, `Space`/`W`/`Up` לקפיצה, `S`/`Down` או `הגנה` לחסימה, `K`/`E` או `מכה` למכה קרובה, `Shift` או `התחמקות` לבריחה מפגיעה, `F`/`J` או `יכולת` למהלך מיוחד, `R` מתחיל מחדש אחרי ניצחון.
